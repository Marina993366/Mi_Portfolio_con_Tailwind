## ✨ Sobre el proyecto

Este portfolio fue creado como parte de mi proceso de formación como **desarrolladora web**.  
El objetivo es contar con un sitio claro, responsive y profesional que permita:

- Presentar mis proyectos más relevantes
- Mostrar mis habilidades técnicas
- Facilitar el contacto y el acceso a mi GitHub
